# P4 manifest and MIDI contract (2026-10-08)

Pitch bend and sustain are handled in `NoteOnlySynthesiser::handleNoteEventNoLock`. `juce::Synthesiser::renderNextBlock` is not used. Wheel centre is 8192 and the range is a fixed +/-2 semitones, so existing preset XML stays valid. CC 64 >= 64 holds a released note until the pedal goes up.

`tools/MidiContract.cpp` renders the processor. It fails if a full-up wheel is not within 2% of `2^(2/12)`, or if a sustained tail is not at least 4x the released tail.

P4 evidence is `scripts/write_soundcraft_manifest.py`. It hashes the built VST3 and an optional REAPER wav. It does not render. A missing file is a failure. REAPER stays on `scripts/reaper_eef_instrument_smoke.lua` and is not a GitHub Actions job.
